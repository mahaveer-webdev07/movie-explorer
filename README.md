# 🎬 MovieBox

A movie discovery app built with HTML, CSS and vanilla JavaScript using the TMDB API.

**Live Demo:** https://mahaveer-webdev07.github.io/movie-explorer/

![Home](screenshots/home.png)

## Features
- Trending movies of the week
- Debounced search
- Genre filters
- Movie details popup with cast and trailer link
- Watchlist with "watched" tracking (saved in localStorage)
- Load more pagination
- Responsive yellow and black UI

## Tech Stack
HTML, CSS, JavaScript (ES6), TMDB API

## Run Locally
1. Clone the repo
2. Get a free API key from [themoviedb.org](https://www.themoviedb.org)
3. Add your key to `config.js`
4. Open `index.html` with Live Server
